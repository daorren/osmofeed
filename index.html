    Stringly Typed (#blogPost)
    I learned a new software development term from Scott Hanselman: "stringly typed". Scott describes "stringly typed" as follows: [whenever] you are passing strings around when a better type exists. An application is "stringly typed" when type information is available, yet you're calling other systems or functions based on strings or stringified data.
