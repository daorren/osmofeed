    Target=_blank implies rel=noopener (#tilPost)
    If you want to be a good web citizen, you might be aware of the target="_blank" security issue. In the old days, when you linked to a site and wanted to open a new tab with target="_blank", the target site could access your site via window.opener. In short: If window A opens window B, B.opener returns A. If you haven't heard of this behavior, it's pretty wild because it implies that target pages could check if window.opener is accessible and if so change the location of your site with trivial JavaScript. if (window.opener) { window.opener.location = 'https://you-re-hacked.com'; } Ooooff...
